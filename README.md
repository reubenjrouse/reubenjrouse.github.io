# reubenjrouse

Personal site. Plain HTML + CSS, no build step.

```
index.html     all content
style.css      all styling (font is set at the top)
images/me.jpg  profile photo
```

## Editing

- **Content:** edit `index.html`. News, Publications and Writing are commented-out
  templates; delete the `<!--` and `-->` around one to turn it on, then copy the
  block for each new entry.
- **Font:** change the two marked lines at the top of `style.css`.
- **Preview:** open `index.html` in a browser.

## Deploying

Any static host works as-is (Vercel, Netlify, GitHub Pages). No build command; the output directory is the repo root.
